# Pitch for Meal Whiz by Terminal Trio
Project Name: Meal Whiz
Team: Terminal Trio

## Initial Situation
Finding recipes that use what’s already in the fridge is difficult and time-consuming.
This leads to food waste and frustration from searching for recipes that only use some ingredients.

## Key feature
Meal Whiz allows users to input their ingredients and receive personalized recipe suggestions from our database, reducing food waste and enhancing kitchen creativity.

## Possible Features
Features added if enough time is left.

Comments and Ratings: Share feedback and rate recipes.
Shopping List:
Gamification: Earn points for dishes, difficulty levels, and time spent; share proof with a photo and climb the leaderboard.
Diary/Cooking History: Track your cooking journey.
Introductory Tutorial: Simple guide for new users.
Recipe of the Week: Featured recipe for extra inspiration.
Add Your Own Recipes: Submit personal dishes.
Nutritional Information: View the nutritional breakdown of each meal.
