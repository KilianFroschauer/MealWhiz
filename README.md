# MealWhiz
MealWhiz is a recipe-finding website designed to suggest recipes based on ingredients users already have at home. Created as a school project, it aims to promote sustainability by reducing food waste and offering a streamlined, enjoyable cooking experience. Users will benefit from features like personalized recipe suggestions, an optional shopping list, user ratings, a leaderboard, cooking history, and nutritional information.
Key Aspects

    Technologies & Tools:
        Frontend: HTML, CSS, JavaScript, TypeScript (using Vite and React).
        Backend: C# (Visual Studio).
        Database: PostgreSQL with management through Datagrip.
    Objectives:
        Develop a reliable, user-friendly interface for fast, accurate recipe suggestions.
        Encourage user engagement through gamification features like a points system and leaderboards.
        Leverage free, open-source tools to maintain a low-cost budget.
    Challenges:
        Building an algorithm to match recipes with available ingredients.
        Implementing a recipe database and gamification features.
        Ensuring compliance with copyright and data protection laws.
